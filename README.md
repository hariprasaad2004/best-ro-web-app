# Best RO Web App

Web application platform for **Best Water Systems** — featuring product catalog, multi-brand purifiers & softeners (Kent, Olivar, Nile), festive offers, enquiry management, and booking system.

## Project Structure
- `documents/` — Product catalog specifications, mockups, design assets, and development user stories.
  - `documents/mockup/` — Prototype UI templates, CSS stylesheets, and scripts.
  - `documents/stories/` — Step-by-step implementation stories and roadmaps.
